# Mohammad Rafiq Siddiqi — Portfolio

Static responsive multi-page portfolio prototype. No framework or build tooling required.

## Preview
Open `index.html` in a browser. All pages link to each other through the persistent sidebar.

## Pages
Home, About Me, Skills, Focus, Projects, What I Do, Certificates, Contact Me.

## Assets
- `assets/portrait-home.jpg`: Home page portrait
- `assets/portrait-close.jpg`: About page portrait
- `assets/certificate.png`: certificate image (if included in this package)

## Notes
- The phone number is intentionally omitted from the public contact page.
- Campaign Overview figures and Campaign Report figures are shown as separate reports.
- Research project is described as a protocol/planning document, not completed field research.
- Google Business Profile is used as the likely intended product name pending confirmation.
- Proficiency levels are not artificially rated.
- Prototype is not deployed and should be reviewed in browser, particularly mobile, before publication.
